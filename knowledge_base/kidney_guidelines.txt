KIDNEY FUNCTION GUIDANCE

Topic: Kidney function and medication safety

General principles:

1. Kidney function is commonly assessed using measurements such as serum creatinine and estimated glomerular filtration rate (eGFR).

2. Changes in kidney function may be relevant when reviewing medications.

3. Some medications require special consideration or dose adjustment when kidney function is reduced.

4. Kidney function may need to be monitored periodically depending on the patient's condition and medications.

5. Medication changes should be reviewed by an appropriate healthcare professional.

6. This document is a general reference and is not a substitute for professional medical advice.
